# The History

This part records what happened and what was planned, as the Rust release notes and RFCs do. It is frozen: a page here is not rewritten when the system changes, so its names, paths, and links may be out of date. The present is in [the reference](../reference/README.md) and [the book](../book/ch00-introduction.md).

- [Session log](../sessions.md): every engineering session, newest first, with commits.
- [Architecture notes](architecture-notes.md): old names, early decisions, and work done before the session log.
- RFCs, the plans as they were approved: [core audit](rfcs/core-audit.md), [agent end-to-end testing and IPC](rfcs/agent-e2e-and-ipc.md), [shell interception](rfcs/shell-interception.md), [menu redesign](rfcs/menu-redesign.md), [motion plan](rfcs/motion-plan.md), [the udtk migration](rfcs/udtk-migration.md), [no WASM](rfcs/wasm.md).

The history is not part of the installed book. Its links in the installed copy open the repository on GitHub.
