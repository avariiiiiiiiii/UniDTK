# The Modules

Each page here describes one module the way the standard library documentation describes one type: what it is for, how it works inside, and how it fails. Every module follows the same shape and contract, stated in [the reference](../reference/modules.md); [Chapter 7](../book/ch07-project-a-module.md) of the book builds one from nothing.

| Module | Backend | What it does |
| :--- | :--- | :--- |
| [clock](clock.md) | none | Time and date on the desk. |
| [explorer](explorer.md) | Rust | A file manager with tabs. |
| [glyph-bar](glyph-bar.md) | Rust | The system volume as LED segments. |
| [micrographics](micrographics.md) | Rust | Weather and place as small graphics. |
| [mp3-player](mp3-player.md) | Rust | Music through libmpv, with the [AI DJ](mp3-player-ai-dj.md). |
| [telegram](telegram.md) | Rust | A Telegram client over TDLib. |
| [vpn](vpn.md) | Rust + helper | sing-box with a TUN adapter. |
