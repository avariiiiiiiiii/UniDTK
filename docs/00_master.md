# UniDTK — Master Map of Content (MOC)

> **Как пользоваться этой документацией:** Это центральный инженерный дашборд (L1-роутер) для ИИ-агентов и разработчиков. Документ читается за 1–2 минуты, фиксирует текущее проверенное состояние системы и маршрутизирует ко всем специализированным спецификациям. При старте любой задачи агент **обязан** начинать анализ с этого файла (Ступени 1–2 протокола `AGENTS.md`).

## 1. Экспресс-дашборд состояния проекта

> [!IMPORTANT]
> **Текущий инженерный фокус:** Миграция с Chromium WebView2 на нативный легковесный GPU-фреймворк **GPUI** (Zed GUI) в ветке `feature/gpui-desktop`.  
> **Статус миграции:** Успешно завершены **Gate 0** (прозрачное окно на WorkerW, 0% CPU) и **Gate 1** (дизайн-система Nothing OS, шрифт Ndot 55, виджеты `clock` и `glyph-bar` на WASAPI, динамический Hit-Testing через Prepaint Taffy).  
> **Завершено 2026-10-20 (сессия 114):** Пятиэтапная миграция дизайн-токенов — оболочка WebView2 полностью перекрашивается из одного объекта темы: движок v2 (только примитивы в JS, деривации в CSS `:root`), свип 1189 хардкодов, `styles.css` разрезан на ядро + 5 пер-модульных CSS, canvas-кэш токенов по событию `unidtk-theme-changed`.  
> **Завершено 2026-10-22 (сессия 116):** Название места в микрографике — цепочка BigDataCloud→Nominatim (DPI-блок BDC больше не глушит панель, атрибуция в secondary); релизный конвейер ускорен в ~2,5×: NSIS `zlib`, 331 МБ AI DJ-модели выброшены из пейлоада установщика (докачка в AppData через `mp3-player/model_fetch`), `udtk build -j 3` без OOM — полная сборка ~11,5 мин, установщик 126 МБ.  
> **Завершено 2026-10-24/25 (сессии 117–123):** Sea Glass v3 откачен; раскладка возвращена к эталону 20.10; схема темы v3 (шрифты + дефолты геометрии как токены); Sea Glass светлый — мятное стекло с глянцем на всех поверхностях, аква, морская микрографика, свип хардкодов; Classic без регресса; переключение тем раскладку не двигает. Процесс: дизайн — живьём инжектом, сборка — один раз по факту.  
> **Завершено 2026-10-28 (сессия 130):** баги меню кастомизации — профиль анимаций больше не сбрасывается, одна очередь записи конфига (тема без потерь при выходе), действия меню не пересобирают стол (`syncWidgets`), VPN не затирает настройки при сбое загрузки, дефолтная раскладка — из ядра, 38 ярлыков перенесены из старого `Shell`. Открыто: UX и CSS меню — [`tasks/menu-audit.md`](tasks/menu-audit.md), план переделки (ждёт sign-off) — [`tasks/menu-redesign.md`](tasks/menu-redesign.md).  
> **Завершено 2026-10-28 (сессия 129):** скролл тачпадом над шеллом работает (подтверждено пользователем) — ядро читает контакты тачпада через сырой HID, т.к. над WebView2 Windows отдаёт жест в DirectManipulation и колеса не синтезирует.  
> **Завершено 2026-10-27 (сессия 128):** колесо мыши — через `WH_MOUSE_LL`; раскладка больше не съезжает после сна; открытие папок в проводнике без длинных задач.  
> **Завершено 2026-10-27 (сессия 127):** AI DJ снова переключается; морфы без моргания (часы, чат телеграма, проводник), аватары перетекают рельса ⇄ список, glyph-bar перетаскивается с прилипанием; проводник: длинные задачи 0.7–1.1 с → 0.12–0.17 с; меню и проводник в оттенке Sea Glass; радиусы jelly на токенах. Открыто: скролл тачпадом (ждёт подтверждения).  
> **Завершено 2026-10-27 (сессия 126):** Sea Glass v4.1 — раскрытые карточки и попапы в светлом оттенке своего виджета (`surfaceTint`, `data-surface-tint` для порталов), glyph-bar желейным ползунком, у каждого пользователя своя случайная расцветка (`rollColors` → `userColors` в redb, «Перемешать / Вернуть»), хардкод jelly-CSS переведён на токены `--jelly-hi-rgb`/`--well-rgb`.  
> **Завершено 2026-10-26 (сессия 125):** Sea Glass v4 — схема тем v4 (материал `flat|jelly`, 8 пастельных слотов + `tintMap` на виджеты/панели/группы микрографики, оптика зерна/кромки/тени/чернил, миграция старых записей); у каждого виджета свой пастельный оттенок, текст — глубокие чернила того же тона (OKLCH, ≥7:1); микрографика пилюлями по группам; светлые панели меню/проводника/телеграма; раздел меню «Материал» делает всё настраиваемым; блюр 0 — CPU простоя 0.31%, GPU 0.4%; Classic без регресса.  
> **Завершено 2026-10-26 (сессия 124):** Физическая оптика Sea Glass: схема токенов расширена оптическими скалярами `glassRim`, `glassSheen`, `glassShadow`; каустические тени и SSS-градиент; ликвидированы хардкодные `:root[data-theme="sea-glass"]` правила карточек; читаемость микрографики через капсулу и глубокий темно-морской токен `rgb(var(--fg-rgb))` вместо слепого `#fff`; океанический акцент Deep Sea Teal (`#007780`) вместо красного; Classic без единого пикселя регресса.  
> **Продакшн-база:** Стабильный релиз `C:\Program Files\UniDTK` (Tauri v2 + WebView2) функционирует штатно и собирается одной командой `udtk build`.

## 3. Топология кодовой базы (Карта компонентов)

```
UniDTK Repository
├── core/                       # Ядро системы (инварианты, которые нельзя выключить)
│   ├── api/                    # unidtk-api: чистый стабильный контракт (Module trait, ModuleDb, StoreSpec)
│   ├── kernel/                 # unidtk: микроядро, IPC (26540), трей, хранилища redb, привязка WorkerW
│   └── ui/                     # WebView2 фронтенд: menu.js, surface-manager.js, motion.js, styles.css
│
├── hosts/                      # Графические хосты оболочки
│   └── gpui/                   # unidtk-gpui: нативный GPU-хост на Zed GPUI (DirectX 11 + DirectComposition)
│
├── modules/                    # Вертикальные слайсы функциональности (можно отключать)
│   ├── clock/                  # Часы: ui/ (WebView2) + tests/
│   ├── glyph-bar/              # Светодиодный индикатор громкости WASAPI Nothing OS
│   ├── mp3-player/             # Плеер: rust/ (libmpv FFI) + ui/ (граф AI DJ, дуги)
│   ├── micrographics/          # Амбиентная инфографика: rust/ (WinRT гео) + ui/ (сетка)
│   ├── telegram/               # Мессенджер: rust/ (TDLib FFI) + ui/ (чаты, треды)
│   ├── vpn/                    # VPN: rust/ + helper/ (vpn-helper.exe) + ui/
│   └── explorer/               # Проводник: ui/ (вкладки, навигация)
│
├── opt/                        # Вспомогательные нативные утилиты
│   └── cli/                    # udtk.exe: канонический CLI-инструмент разработчика
│
├── toolchain/                  # Сборочная инфраструктура
│   ├── Cargo.toml              # Единый Cargo-манифест для релизной сборки
│   └── windows/hooks.nsh       # Хуки инсталлятора NSIS для Program Files
│
└── scheduler-tasks/            # XML-шаблоны задач Task Scheduler (UniDTK, Singbox, VpnStop)
```

## 5. Правила обновления документации для агентов

1. **Единый стандарт ссылок:** Все ссылки внутри проектных документов обязаны быть стандартными относительными Markdown-ссылками вида `[Текст](относительный_путь.md)`. Использование `[[wikilinks]]` за пределами персональных заметок запрещено.
2. **Breadcrumbs в каждом документе:** Каждый дочерний документ обязан содержать в первой строке под заголовком навигационную цепочку возврата в `00_master.md`:
   `> [← UniDTK Master MOC](00_master.md) | [Архитектура](architecture.md) | [Журнал сессий](sessions.md)`
3. **Обновление по Ступени 10:**
   - Каждая завершенная сессия **обязательно** фиксируется в [`docs/sessions.md`](sessions.md) с привязкой к дате и Git Commit SHA.
   - Экспресс-дашборд и таблица статуса в [`docs/00_master.md`](00_master.md) обновляются при переходе на новые гейты, добавлении документов или изменении метрик рантайма.
   - Нормативная книга [`docs/architecture.md`](architecture.md) обновляется **только** при изменении архитектурных контрактов ядра или модулей.
