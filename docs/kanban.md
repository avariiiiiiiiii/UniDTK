## 🧱 Ядро (Core)

> **Принцип: ядро = НЕ то, что видит пользователь.** Ядро — невидимая инфраструктура, на которой работает всё видимое: каркас (окна/оверлеи/layout), система виджетов (загрузка/размещение/drag/resize), реестр команд + шина событий, единая БД (redb), сервисный слой (FS/сеть/аудио), загрузчик модулей. Проверка: «если выключу — шелл перестанет быть шеллом?»

- [ ] **Реестр команд + шина событий** — единый фасад: `invoke` / `events` / `db`
- [ ] **Стабильный API для модулей** — контракт: команды, события, БД, права (grants)
- [ ] **Системные сервисы как платформа** — FS, Telegram, VPN, музыка, wallpaper, volume/audio/input
- [ ] **Менеджер модулей** — манифесты, enable/disable, hot-reload, песочница
- [ ] **CLI** — `shell build|dev|run|mods|theme|ai|doctor` (замена VBS, мост для ИИ и модулей)
- [ ] **Система логов в единую БД** — таблица `LOGS` в redb; пишут бэкенд (все команды/ошибки) И фронтенд (console.log/ошибки через invoke); ротация (cap по размеру/времени), экспорт через CLI (`shell logs`); не блокирует, но диагностируемо
- [ ] **Меню настроек** — замена кнопки перемещения: размещение виджетов, добавление/создание, стили, анимации

## 🌉 Мосты (Bridges)

> **Меню настроек = МОСТ, а не модуль и не ядро.** Его нельзя выключить. Меню решает: какие модули включены, как работают анимации, какие стили, как работает ИИ и какой ИИ подключён. Это «панель управления» шеллом.

- [x] **Меню настроек = мост** — решает модули/анимации/стили/ИИ; не выключается
- [ ] **Модульный мост** — модуль ↔ ядро: `invoke`/`events`/`db` с grants
- [ ] **CLI-мост** — CLI ↔ ядро: тот же контракт (UI/CLI/ИИ/Lua — все клиенты одного API)
- [ ] **ИИ-мост (MCP)** — встроенный ИИ читает/пишет модули, конфиги, стили, токены через CLI/API
- [ ] **Управление бинарниками как сервисами** — libmpv/yt-dlp/sing-box: spawn + health-check + restart, скрыто за API

## 📌 Заметки

- **Правило границы:** ядро = то, без чего шелл перестаёт быть шеллом (PR/меня); модули = всё, что можно выключить (любой пользователь через API)
- **Lua — не отдельный бинарник:** mlua компилирует интерпретатор в shell.exe (vendored), ноль внешних зависимостей
- **WASM — убран:** лишний слой, Lua-песочница + Rust нативно уже решают изоляцию
- **Бутстрап:** Cargo-тулчейн внутри = ~2GB, WebView системный — не «съесть»; сладкая точка — встроенный Lua/Rust-слой
