# Аудит меню кастомизации

> Только проблемы, без решений. Источники: живой прогон установленной сборки `f16cedd` (скриншоты `udtk shot`, `udtk gui tree`, `udtk gui js`) и чтение кода 4 субагентами (Haiku 5.5) с выборочной ручной проверкой. Метка **[жив]** — воспроизведено в рантайме, **[код]** — проверено чтением кода агентом-оркестратором, без метки — находка субагента, не перепроверенная вручную.

## 1. Потеря данных и сломанное поведение

1. **[жив]** Клик по пилюле шрифта, материала, раскладки микрографики или «Перемешать/Вернуть» сбрасывает «Профиль динамики переходов». Обработчик `.theme-motion-pill` висит на всех этих кнопках, `dataset.profile` у них пуст → `setLiveToken("motionProfile", undefined)` → профиль падает на «Сбалансированный». Воспроизведено: «Плавный» → клик по уже активному «Морское стекло» → «Сбалансированный». `core/ui/menu.js:1399-1406`, классы на `1100, 1115, 1197-1213, 1221-1222`.
2. **[код]** Почти любое действие в меню (видимость виджета, X/Y, сброс позиций, создание/переименование/удаление папки, добавление/удаление ярлыка) зовёт `loadWidgets()` → `widgetsCanvas.innerHTML = ""` и перечитывание конфига: плеер, телеграм, часы пересоздаются. `menu.js:297, 361, 533, 550, 562, 603, 622`; `unidtk-core.js:366`.
3. **[код]** Две независимые очереди записи в один blob `config`: тема — через `saveChain` с debounce 600 мс, меню — `saveWidgetConfig(config)` напрямую, без `syncThemeIntoConfig`. Порядок коммитов не гарантирован, в redb может уйти старая тема. `menu.js:296, 332, 360`; `theme.js:1107-1136`; `unidtk-core.js:123-129`.
4. **[код]** Нет flush при закрытии (`beforeunload`/`pagehide` отсутствуют) — изменение темы в последние 600 мс перед выходом теряется. `theme.js:1124-1136`.
5. **[код]** Ошибка `vpn_settings` молча рисует форму с пустыми дефолтами; «Сохранить подписку» / «Сохранить сервер» затем перезаписывают реальные настройки пустыми. Ошибка только в консоли. `menu.js:642-661, 774-790, 808-835`.
6. **[код]** После сворачивания карточки папки её иконка пропадает: тело очищается, а восстановление читает `config.folders` (никем не заполняется) и `window.__renderFolderIcon` (нигде не определена). `unidtk-core.js:664-668, 1126-1130`.
7. Если источник конфига не `redb` (сбой `get_widget_config`, битый JSON), `saveWidgetConfig` весь сеанс молча ничего не пишет; меню показывает успех. `widgets-api.js:202-221`.
8. Гонка двух быстрых переключателей бэкенд-модулей: второй затирает первый; при `ok === false` чекбокс остаётся в неверном состоянии. `menu.js:304-313`.
9. Нет блокировки кнопок на время `invoke`: двойной клик создаёт две папки / два ярлыка / два VPN-запроса; id `folder_${Date.now()}` может совпасть. `menu.js:518-538, 571-609, 774-835`.
10. `config.hidden` мутируется до сохранения без try/catch — неудачное скрытие «доезжает» в redb со следующим удачным сохранением. `menu.js:292-296`.
11. «Сброс позиций» пишет glyph-bar и telegram `w:340, h:64` — расходится с дефолтами (`unidtk-core.js:138-139`, `widgets-api.js:168-171`), очищает `hidden`, не трогает `instances`. `menu.js:349-359`.
12. Дефолтная раскладка задана дважды и по-разному: `core/kernel/main.rs:2226-2240` (clock x:510) и `widgets-api.js:163` (x:28).
13. `relayoutWidgets()` при пустом холсте зовёт `loadWidgets()` (сброс DOM) — нарушение правила архитектуры §4. `unidtk-core.js:2201-2205`.

## 2. Данные и хранилища

14. **[жив]** Ярлыки папок указывают на `%LOCALAPPDATA%\Shell\folders\…\shortcuts\*.lnk` — каталог от старого имени проекта. Он жив рядом с `UniDTK` и содержит `sing-box.exe`, `vpn-helper.exe` (программы в AppData — против правила «программа в Program Files»). Чистка `Shell` сломает все ярлыки.
15. Четыре носителя состояния темы без сверки на старте: localStorage, `config.theme` в redb, память, слепок `paint` в `index.html`. Комментарий «redb авторитетен» неверен: пустой redb воскрешает цвета из кэша. `theme.js:1141-1190`, `index.html:14-19`.
16. Blob конфига без версии и без проверки: `set_widget_config` принимает любой JSON и заменяет весь ключ. `core/kernel/unidtk_db.rs:118-127`.
17. Миграция старых пресетов молча подставляет поля из Nothing Classic; встроенный Sea Glass старой схемы теряет палитру вопреки комментарию. `theme.js:517-562, 36-38`.
18. «Перемешать» на Classic перезаписывает палитру встроенного пресета навсегда. `theme.js:896-899`.
19. Live-путь слайдеров пишет значения без clamp/валидации (`radiusSurface = val + 8` без верхней границы, шрифт из `dataset` без сверки). `theme.js:859-879`, `menu.js:1377, 1305`.
20. Границы слайдеров и схемы расходятся: blur 36 vs 48, radius 28 vs 32.
21. Каждый `change` слайдера — синхронная запись всего JSON в localStorage + полный blob в redb.

## 3. UX — вкладка «Виджеты и стол»

22. **[жив]** У каждой карточки два переключателя без объяснения: верхний (показ на столе) и «Модуль (бэкенд)». Бэкенд-понятие выставлено пользователю; у Clock второго нет → карточки разной высоты, ряд «Координаты» скачет.
23. **[жив]** Позиция — сырые X/Y в px (Clock Y = −3). Нет границ, отрицательные принимаются, пустое → 0. Размера нет вовсе.
24. **[жив]** Подписи «Модуль системы» у всех карточек — пустая информация; названия виджетов по-английски (Clock, Glyph Bar, Micrographics) в русском интерфейсе.
25. **[жив]** Цветная эмодзи-иконка у «Переместить на столе» — единственная цветная иконка в меню.
26. «Переместить на столе» молча закрывает меню; выход из режима редактирования — только повторным кликом по кнопке на столе, Escape не работает. `menu.js:338-343`, `unidtk-core.js:1903-1908, 2083-2095`.
27. Перетаскивание: без границ экрана, сетки, направляющих, проверки перекрытий, отмены; `pointercancel` фиксирует позицию. `unidtk-core.js:1781-1840`.
28. Позиции — абсолютные CSS px без привязки к размеру экрана; клампа нет (кроме telegram с магическими 1200/1700). Другой монитор — виджеты за экраном. `unidtk-core.js:158-171, 418-421`.
29. Скрытие по типу скрывает все инстансы; вернуть инстанс отдельно нельзя. `unidtk-core.js:377-383`.

## 4. UX — вкладка «Папки ярлыков»

30. **[жив]** «(1 ярлыков)» — без склонения. `menu.js:438`.
31. **[жив]** Описание «Данные хранятся в базе redb» — деталь реализации для пользователя.
32. **[жив]** Тип «FILE» латиницей капсом; плейсхолдер «Имя ярлыка (YouTu» обрезан; путь обрезан многоточием.
33. **[жив]** Поле имени папки выглядит как заголовок — не видно, что оно редактируемое; сохраняется только по blur, без подписи (`gui tree`: `name: null`).
34. Ярлык нельзя редактировать — только удалить и создать заново; нет переупорядочивания, drag&drop файлов, выбора файла через диалог.
35. Нет валидации цели: «Веб (URL)» принимает `C:\…`, «youtube.com» без схемы уходит в ветку файла; дубли не проверяются. `menu.js:571-609`, `widgets-api.js:289-296`.
36. Удаление ярлыка — без подтверждения; удаление папки — нативный `confirm()`; ошибки — нативный `alert()` (блокирует, не в стиле оболочки), а VPN использует тосты.
37. Удаление папки не чистит `positions`/`hidden`/`instances`. `menu.js:556-568`.
38. Переименование мутирует модель до сохранения, без try/catch, пустое имя — пустое поле без отката. `menu.js:541-553`.

## 5. UX — вкладка «VPN и Сеть»

## 6. UX — вкладка «Оформление»

44. **[жив]** Одна прокрутка на 1557 px при видимых 489 (3+ экрана), ~50 контролов, без навигации по секциям.
45. **[жив]** Смешение языков: «(Glass Opacity)», «(Blur Strength)», «(Corner Radius)», «(Motion Duration Scale)», «(пресетный токен)», «Виджет // Превью», «Live», «UNIDTK // MENU».
46. **[жив]** «Живой предпросмотр — применяется сразу», но меню закрывает весь стол — эффекта на виджетах не видно. Превью-карточка — фейковый белый виджет, не перекрашивается оттенком; «Уровень сигнала 64%» статичен, «Aa» не обновляется.
47. **[жив]** Чипы акцента (красный, оранжевый, циан…) не из палитры Sea Glass; текущий акцент `#4a5fc1` не среди чипов — выбранное не подсвечено.
48. **[жив]** Невыбранные пилюли — голый текст без рамки (не читаются как кнопки); «Перемешать цвета» / «Вернуть прошлые» выглядят как текст.
49. **[жив]** Ритм нарушен: подписи «Микрографика», «Аватары Telegram» прилипают к контролам выше.
50. **[жив]** «Цвет 1…6» — имена без смысла; палитра квадратами, оттенки виджетов кругами; «Панели: меню, прово…» обрезано.
51. **[жив]** Заголовки секций: Ndot в трёх вкладках, Geist в «Оформлении» — два шрифта для одной роли (`menu.css:230-239` vs `693-702`).
52. Необратимые действия без подтверждения и undo: удаление пресета, «Сбросить размеры», «Перемешать» (откат — один шаг, в памяти). Нет экспорта/импорта/полного сброса темы.
53. Перерисовка всей вкладки после почти каждого изменения — теряются фокус, прокрутка, открытый color picker. `menu.js:1276-1452`.
54. «Тест анимации»: без catch, повторные клики плодят анимации и таймеры. `menu.js:1488-1502`.

## 7. Общая оболочка меню

55. **[жив]** Гамбургер в шапке без понятной функции; заголовок «UNIDTK // MENU» — dev-стиль.
56. Меню — модальный оверлей почти на весь экран: правки раскладки и цвета нельзя видеть одновременно с виджетами.
57. Асинхронные рендеры вкладок без токена запроса: быстрое переключение — старый ответ перезаписывает новый. `menu.js:127-175`.
58. Ошибка загрузки = ложное пустое состояние («Нет созданных папок», пустая сетка) или вечное «Загрузка…». `menu.js:177-184, 381-384`.
59. Enter не отправляет ни одну форму (папка, ярлык, подписка, пресет).
60. «После перезапуска» без кнопки перезапуска.

## 8. Доступность и CSS

61. Нет `:focus-visible` нигде; `outline: none` без замены (`menu.css:303, 850, 926`); единственная замена — белое кольцо 8% (невидимо на светлой теме).
62. Контраст ниже 4.5:1 (расчёт по токенам): описания секций 12px α0.45 (Sea Glass ≈2.7:1), неактивные табы α0.55 (≈3.6:1), плейсхолдеры α0.28 (≈2.5:1), заголовки таблиц, `.widget-mgmt-type`, кнопка «Удалить».
63. Мелкие цели: точки оттенков 20×20, ползунок 6px, «Удалить ярлык» 28×27, удаление пресета без размера.
64. ARIA: табы без `tablist/tab/aria-selected`, диалог без `role=dialog`/`aria-modal`, фокус не переводится внутрь и не возвращается; пилюли без `aria-pressed`; слайдеры без связанной `label`.
65. Sea Glass: jelly-переопределения покрывают только табы/карточки/слайдер — белые рамки на `bg-elev` 255 почти невидимы у шапки, кнопок, инпутов, пресетов, пилюль (`menu.css:65-1088`).
66. Хардкод вне токенов: фон оверлея `rgba(5,5,8,.72)` вместо `--scrim-rgb`, blur 16px, радиусы 6–24px, тени, `#e6e6e6`, рамка danger `rgba(215,25,32)` (32 вместо 33), ~20 мёртвых fallback `#d71921`; inline-стили в `menu.js` (`205, 236-271, 403-413, 680`).
67. `transition: all` (10 мест), кривые `ease` вместо токенов (17 мест), `translateY(6px)` в keyframes.
68. `z-index` меню = проводнику (2000), токен `--z-surface-menu` (4000) не используется.
69. Фиксированные колонки (340px, 140px/110px) и медиазапрос по viewport, а не по контейнеру.
70. Три класса на одно состояние открытия (`visible`, `surface-active`, `surface-open`).
